````markdown
# Astro Bumpers — Knockout Arena
Arcade-style, physics-driven, TV-hosted party brawler for **1–12 players**. Phones are controllers; the TV/computer browser is the arena display. Rounds are short, juice is high, and the server is fully authoritative.

> **Elevator pitch:** Steer and boost space bumper-ships to smash opponents off dynamic arenas full of hazards and power-ups. Laughs, sparks, and slow-mo KOs in ~90-second rounds.

> **Zero-Asset Build:** This project is designed so an AI (or human) can build and ship it **with no external images, sprites, or audio files**. All visuals are **procedurally drawn** (Canvas/WebGL primitives), icons are **vector glyphs** rendered at runtime, particles are programmatic, and all SFX/music are synthesized with **WebAudio**. PWA icons are generated by a build script.

## Goals & Non-Goals
**Goals**
- Feel like an arcade machine: **immediate fun**, minimal reading, giant feedback.
- **1–12 players**, smooth on mid-range phones over local Wi-Fi or internet.
- **Authoritative server** to ensure fairness; clients send only intents.
- **Short rounds** (60–120s) + easy rematch loop.
- **Zero external assets** (no PNG/JPG/MP3/OGG): visuals and audio produced **entirely in code**.

**Non-Goals (v1)**
- Cross-room matchmaking, user accounts, cosmetics store.
- Native apps (mobile web/PWA only).
- Imported art/audio pipelines.

## Game Design

### Core Loop
1. **Host opens TV/desktop** and creates a room (QR + 4-char code).
2. **Players join on phones**, pick color/emoji; quick control test.
3. **Countdown 3-2-1 → Round** (~90s). Smash, dodge, power-ups.
4. **Podium & fun awards** → instant **Rematch** or change map/mode.

### Modes
- **Last-Alive (Default):** Fall off = lose a life; last remaining wins round.
- **Stock Lives:** 3 lives; most lives left wins on time-up.
- **King of the Ring:** Points accrue while holding center; highest wins.
- **Coin Chomp:** Collect stars; must **bank** at stations to secure.

### Controls
- **Option A (default):** Three giant buttons — **Left**, **Right**, **Boost**.  
  Press **L+R** = brake/rotate damp.
- **Option B:** **Thumb Wheel** (virtual steering ring) + **Boost** button.
- Assist toggles: **Auto-throttle** (slow constant forward), **Steer Assist** (limits over-rotation).

### Power-Ups
Simple, readable effects (one active at a time):
- **Nitro** — burst speed.  
- **Shockwave** — next hit emits radial push.  
- **Heavy** — higher mass & stability.  
- **Glue Tires** — higher friction/handling.  
- **Ghost** — brief phase-through collisions.  
- **Tractor** — soft pull on nearest foe.

### Hazards
- **Rotating Maces**, **Edge Lasers (blinking)**, **Mini Black Holes**, **Conveyors**, **Pinball Bumpers**.

### Maps
1. **Launchpad:** Small circle; easy ring-outs.  
2. **Beltway:** Conveyors on edges.  
3. **Pinball:** Bumpers & flippers.  
4. **Spokes:** Pie slices with radial gaps; safe center.

### Scoring & Win Conditions
- Match = **best of 3 rounds** (configurable).  
- Ties break by **KOs**, then **stars collected**.  
- Fun awards: “Freight Train” (largest single impulse), “Spin Doctor” (most spins), “Survivalist”.

### Bots
- Fill empty slots.  
- Behavior: simple **seek + bump** with hazard avoidance and “don’t fall” edge logic.  
- Aim difficulty: target velocity error < 10% over 500ms.

### Accessibility & UX
- Color-blind-safe palette; strong outlines and drop shadows.
- Large hit areas; adjustable button sizes.
- Minimal text; iconography with short tooltips.
- Vibrations on impact/KO (opt-in).
- System fonts only (no webfont downloads).

## Technical Overview

### Architecture
```mermaid
flowchart LR
  subgraph Controllers (Phones)
    P1((Player 1))
    Pn((Player N))
  end
  subgraph Host (TV/Browser)
    H[Phaser Render Client]
  end
  subgraph Server (Node)
    S1[Room Manager]
    S2[Authoritative Physics (matter-js)]
    S3[State Snapshots & Events]
  end
  P1 -- INPUT intents --> S1
  Pn -- INPUT intents --> S1
  S1 <--> S2
  S2 --> S3
  S3 -- STATE, EVENTS --> H
  S3 -- minimal HUD updates --> P1
  S3 -- minimal HUD updates --> Pn
  H -- host-only UI cmds --> S1
````

* **Server authoritative** simulation (30 Hz).
* **Host** renders snapshots, interpolates, adds juice (screenshake/slow-mo).
* **Controllers** send only **intents** (steer, boost) ~15–20 Hz; low render/no world sim.

### Tech Stack

* **Server:** Node 20 + TypeScript, **Socket.IO** (WebSocket only), **matter-js**, optional **Redis** Pub/Sub for sharding.
* **Host (TV):** **Phaser 3 (WebGL)** for primitives, particles, pipelines; QRCode (Canvas-based) for room join.
* **Controller (Phone):** Vanilla TS + Pointer Events; minimalist PWA shell (no external assets).
* **Audio:** **WebAudio** (no files) via small synth/util (provided in repo).
* **Build:** Vite + TypeScript monorepo (pnpm).
* **Deploy:** Node behind Nginx reverse proxy, HTTPS (Let’s Encrypt).

### Monorepo Layout

```
.
├─ apps/
│  ├─ server/              # Node + Socket.IO + matter-js (authoritative)
│  ├─ host/                # Phaser renderer (TV/desktop) — all vector/primitives
│  └─ controller/          # Mobile PWA controller (vector UI)
├─ packages/
│  ├─ common/              # Shared types, constants, protocol helpers
│  ├─ procedural-gfx/      # Shape drawing, particles, glow, glyphs
│  ├─ synth/               # WebAudio SFX + generative music (no files)
│  └─ icongen/             # Build-time PWA icon generator (Canvas → PNG)
├─ scripts/                # Dev tooling
└─ README.md
```

### Design Tokens (No-Asset Rendering)

To ensure attractive visuals without images, all art uses the following tokens:

**Color Palette**

* `bg0` #0a0f1e (space)
* `line` #1b2550 (grid/edges)
* `p1` #ff5a8a, `p2` #58d7ff, `p3` #ffd262, `p4` #8ef07a, `p5` #c090ff, `p6` #ff8c4b
* `hazard` #ff3b3b, `pickup` #66ffcc, `star` #ffe066, `laser` #ff4d6d

**Strokes & Shadows**

* Outline: 4px outer, 2px inner (dual stroke for readability)
* Drop-shadow: draw 3 offset concentric strokes with alpha 0.15/0.1/0.06
* Glow: render 4 concentric circles with alpha falloff 0.25 → 0.05

**Particles**

* Default burst: 40–80 discs (radius 3–6px), lifetime 400–900ms, easing cubic-out
* Trail: 12–20 particles/sec per ship, shrink 1.0 → 0.0 over 300ms

**Vector Glyphs (rendered with Phaser Graphics/Canvas)**

* **Ship:** Capsule (circle+rect+circle), fin triangles
* **Nitro:** Chevron triple `>>>`
* **Shockwave:** Concentric circles + outward ticks
* **Heavy:** Small square “anvil” icon
* **Glue:** Droplet + small horizontal lines beneath
* **Ghost:** Rounded blob with eye dots
* **Tractor:** Horseshoe magnet silhouette
* **Hazards:**

  * Mace: circle + 8 spikes (isosceles triangles)
  * Laser: rectangle emitter with animated beam
  * Black Hole: 3 spiral arcs (Bezier) rotating
  * Conveyor: chevrons along band

All icons are functions that accept `(ctx, x, y, scale, color)` and draw primitives.

## Networking Protocol

### Transport & Rates

* **WebSocket** via Socket.IO; **disable long-polling** (`transports: ['websocket']`).
* **Server tick:** 30 Hz fixed physics step (33.33ms).
* **Snapshots:** 10–20 Hz (adaptive).
* **Input intents:** 12–20 Hz from controllers.

### Events (Socket.IO)

Namespace `/game`, rooms per match.

**Client → Server**

* `room:create` → `{ public?: boolean, map?: MapId, mode?: ModeId }`
* `room:join` → `{ roomCode, nickname, device:'controller'|'host' }`
* `input` → `{ seq, steer:-1..1, boost:0|1, ts }`
* `host:command` → `{ type:'start'|'rematch'|'switchMap'|'switchMode' }`
* `pong` → `{ ts }`

**Server → Client**

* `welcome` → `{ playerId, roomState, jwt }`
* `room:state` → `{ playersSummary, map, mode, countdown? }`
* `state` → compact snapshot (see schema)
* `event` → typed game events (`KO`, `PWR_PICK`, `SCORE`, `ROUND_START/END`)
* `ping` → `{ ts }`
* `error` → `{ code, message }`

## Authoritative Physics

* **matter-js** on **server-only**.
* Host performs **visual interpolation**; controller has no physics.
* KOs/hits computed server-side using collision impulses & bounds.

**Latency Masking**

* Slight extrapolation (host-side) of linear velocity for 1–2 frames max.
* Generous wall hitboxes; KO requires clear thresholds with 300ms debounce.

---

## Performance Targets

* TV render: **60 FPS**.
* Server physics step: **< 8ms** at 12 players.
* Controller bandwidth: **10–20 KB/s** average.
* First load: **< 2.5 MB JS** (tree-shake; no media assets).

---

## Security & Anti-Cheat

* Server ignores client positions; accepts **intents only**.
* Inputs have **monotonic seq**; old/dup dropped.
* Rate-limit boost; clamp steer range.
* Room-scoped **JWT** for session auth (expires on match end).
* Kick idle/duplicate connections; sanitize nicknames.

---

## Reliability & Reconnect

* Idempotent join via playerId in JWT.
* On disconnect: convert player to **bot**; if reconnect within 30s, reclaim.
* Late joiners **spectate** until next round.

## Implementation Specs

### Message Schemas

> All messages **JSON** initially; migrate to binary later.

**Types**

```ts
type ID = string; // uuid v4
type UnixMs = number;

type ModeId = 'lastAlive'|'stock'|'king'|'coin';
type MapId  = 'launchpad'|'beltway'|'pinball'|'spokes';

interface JoinReq { roomCode: string; nickname: string; device: 'host'|'controller'; }
interface Welcome {
  playerId: ID;
  roomState: RoomSummary;
  jwt: string; // signed, room-scoped
}
interface InputIntent {
  seq: number;           // 0..2^31-1 wraps
  steer: number;         // -1..1 (left/right)
  boost: 0|1;
  ts: UnixMs;            // client local send time
}
interface Snapshot {
  tick: number;
  t: UnixMs;             // server time
  players: Array<{
    id: ID; x: number; y: number; a: number; vx: number; vy: number;
    state: 'alive'|'ko'|'respawn'|'dead';
    lives: number; pwr?: PowerUpId; pwrTtl?: number; stars?: number;
  }>;
  pickups: Array<{ id: ID; x: number; y: number; type: PowerUpId }>;
  hazards: Array<HazardState>;
  events?: Array<GameEvent>;
}

type PowerUpId = 'nitro'|'shock'|'heavy'|'glue'|'ghost'|'tractor';

type GameEvent =
 | { type:'KO'; by:ID|null; victim:ID; impulse:number; t:UnixMs }
 | { type:'PWR'; player:ID; pwr:PowerUpId; ttl:number }
 | { type:'SCORE'; table:Array<{id:ID; kos:number; stars:number; lives:number}> }
 | { type:'ROUND_START'; round:number; mode:ModeId; map:MapId }
 | { type:'ROUND_END'; round:number; winner:ID|null };
```

### Server Tick Loop

```ts
const FIXED_DT = 1000/30; // 33.33ms
let acc = 0, last = Date.now();

setInterval(() => {
  const now = Date.now();
  acc += now - last; last = now;

  while (acc >= FIXED_DT) {
    applyInputsToForces();           // steer→angular, boost→forward impulse (cooldowns)
    Matter.Engine.update(engine, FIXED_DT);
    processKOsAndRespawns();
    updatePickupsAndHazards();
    maybeBroadcastSnapshot();        // every N ticks
    acc -= FIXED_DT;
  }
}, 4);
```

### Snapshot Compression

* Send **Float32** positions, **Int16** velocities after scaling.
* Delta-encode vs. last snapshot per client; drop unchanged fields.
* Bit-pack flags (state, power-up).
* Start with JSON; provide `--binary` flag to switch to ByteBuffer/FlatBuffers later.

### Physics Constants

> Units: **pixels**. World 1920×1080 reference; elements scale to fit aspect.

* Player ship

  * radius: **34 px**
  * mass: **12**
  * restitution: **0.6**
  * frictionAir: **0.02**
  * base thrust (always-on): **0.0012** * mass
  * steering torque: **0.0018**
  * **Boost**: +**1800** impulse over **0.35s**, cooldown **2.0s**
* KO threshold:

  * if center distance > arenaRadius + 40 → **KO**
  * or collision **impulse > 2800** and victim crosses soft bound within 0.8s
* Global gravity: **0** (space)
* Time slow-mo on KO: **0.6s @ 0.5x** (host-only visual)

### Power-Up Specs

| Power-Up  | Duration | Effect                                                                 |
| --------- | -------- | ---------------------------------------------------------------------- |
| Nitro     | 2.0s     | +60% top speed, +25% thrust; trail density ×1.5.                       |
| Shockwave | 6.0s*    | *One-use:* on next collision, radial impulse up to 2200 within 150 px. |
| Heavy     | 7.0s     | mass ×1.7; restitution −0.2; knockback taken −25%.                     |
| Glue      | 7.0s     | friction ×1.8; frictionAir −30%; crisper handling.                     |
| Ghost     | 1.5s     | collision mask off vs players; hazards still affect.                   |
| Tractor   | 2.0s     | pull nearest foe within 300 px @ 600 N; weakens with distance.         |

Spawn rule: 1–3 pickups on map, respawn **3–6s** after pickup at random eligible nodes.

### Hazard Specs

* **Rotating Mace:** rigid body on pivot; angular speed 0.8–1.4 rad/s; knockback 1200–2200.
* **Edge Lasers:** telegraph blink 1.0s, on 2.5s, off 3.0s; contact applies 1600 outward impulse.
* **Mini Black Hole:** field **F = k / (d^2 + ε)** toward center, k=18k, ε=2000; max pull clamp 900.
* **Conveyor:** regions apply constant tangential velocity (additive 220–340).
* **Pinball Bumpers:** restitution 1.3; score bonus +1 star on hit.

### Map Specs

All maps defined as JSON (server authoritative), rendered on host.

```json
{
  "id": "launchpad",
  "bounds": { "type": "circle", "r": 520, "cx": 0, "cy": 0 },
  "spawnPoints": [[-320,-120],[320,-120],[-320,120],[320,120]],
  "hazards": [],
  "pickupNodes": [[-200,0],[0,0],[200,0]]
}
```

Scale strategy: host fits world into viewport with letterbox; server uses world units unscaled.

### UI States

**Host**

* Lobby (room code + QR, connected list, latency dots)
* Countdown
* In-Round HUD (timer, lives, mini-feed of events)
* Podium/Stats (awards, KO table, rematch)

**Controller**

* Connect → Handle selection → Control test
* Big buttons (L/R/Boost) **or** Thumb Wheel + Boost
* HUD chips: lives, active power-up (icon + TTL ring), stars
* Settings: button size, assist toggles, haptics, colorblind filter

### Audio (Procedural)

No audio files are shipped. All SFX/music are synthesized via **WebAudio**.

**SFX recipes**

* **Hit:** white noise → bandpass(1.2kHz, Q=8) → decay 180ms; gain env: 0.0→0.7→0.0 (linear).
* **KO:** sine @ 220→110 Hz glide 250ms + noise burst; compressor to avoid clipping.
* **Boost:** sawtooth @ 440→660 Hz over 350ms; subtle chorus (LFO 0.9Hz, depth 8 cents).
* **Pickup:** triangle arpeggio (880, 1320 Hz), 2 notes × 80ms.
* **Shockwave:** pink noise, low-shelf +6dB < 200Hz, 300ms with quick attack.

**Music (generative)**

* Tempo 112 BPM, 4/4.
* **Drums:** noise → transient shaper for snare; sine pitch envelope for kick.
* **Bass:** minor pentatonic step sequencer (root rotates each round).
* **Lead pad:** square→lowpass (cutoff 1.2kHz), 8-step melody with random ornament 10%.

Provide `packages/synth` util:

```ts
// Pseudocode shape
export function sfxHit(ctx: AudioContext, vol=0.7): void { /* ... */ }
export function sfxKO(ctx: AudioContext): void { /* ... */ }
export function startMusic(ctx: AudioContext): { stop:()=>void } { /* ... */ }
```

### Haptics

* Use `navigator.vibrate` if available; gated by user gesture and opt-in.
* Patterns:

  * **Hit:** `[25]`
  * **KO:** `[60, 30, 60]`
  * **Power-Up:** `[15, 15]`

### PWA (Icon Generator, No Image Files)

* A Node script in `packages/icongen` uses **Canvas (node-canvas or @napi-rs/canvas)** to draw a simple vector “ship” glyph and exports required PNGs (`192, 256, 384, 512`) and `maskable` variants.
* Build step writes files to `apps/controller/public/icons/`. No external images are checked in; icons are produced deterministically from code and [Design Tokens](#design-tokens-no-asset-rendering).
* Manifest references these generated files; install works offline via service worker shell.

## Dev Setup

### Prereqs

* Node **≥ 20**
* pnpm **≥ 9**
* Modern browsers (Chromium/Firefox/Safari) on TV/desktop + mobile

### Install & Run

```bash
# Install dependencies
pnpm i

# Run all three in watch mode (server, host, controller)
# This will automatically build icongen and all packages first
pnpm dev
```

* Server listens on `http://localhost:8787`.
* Host UI on `http://localhost:5173` (env points to server).
* Controller UI on `http://localhost:5174` (env points to server).

Open **Host** on desktop/TV, create room → scan QR with phone to join.

**Note:** The `pnpm dev` command automatically builds all required packages (icongen, common, synth, procedural-gfx) before starting the development servers. If you need to run apps individually, first build the packages with `pnpm --filter './packages/**' build`.

#### Common Issues

* **Typo in command:** Make sure to use `pnpm dev` (not `pnpn dev` or `npm dev`). This is a pnpm monorepo and requires pnpm ≥ 9.

Create `.env` files per app.


### Build & Deploy

* **Reverse proxy (Nginx)**

  * Terminate TLS.
  * Proxy `/socket.io/` to server with `upgrade`/`connection` headers for WebSocket.
  * Cache-bust static assets (Vite hashes).
* **Process manager:** pm2 or systemd (one server process per core if sharded).
* **HTTPS:** Let’s Encrypt; renew automatically.
